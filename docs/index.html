02 / EVIDÊNCIAS

Um laboratório. Várias plataformas.

O nome comercial não determina o processador. Escolha uma família para ver a evidência disponível.

Roteiro experimental

ESTUDO DE CASO
  1. 01
    Identificação sem confiar no anúncio

    SoC H713 e placa tv303 confirmados; fingerprint ADT-3 não é prova de hardware Google.

  2. 02
    Backup por partição + SHA-256

    21 imagens íntegras. bootloader_a e frp negaram acesso. super e dados excluídos por escolha.

  3. 03
    Patch Magisk 30.7 no aparelho

    Boot original de 64 MiB; cópia original e modificada tiveram cabeçalho ANDROID! e hashes diferentes.

  4. 04
    Permissões do root temporário

    /system/bin/wifi tinha UID efetivo 0, mas capacidades efetivas zeradas. Corrigida a legibilidade do patch.

  5. 05
    Gravação confirmada, depois boot

    64 MiB gravados em boot_a, hash pós-gravação correto, auditoria 8/8. Proprietário relatou root funcional.

04 / FERRAMENTAS

Testar antes de arriscar

Utilitários locais, auditáveis e somente leitura. Não há botão de flash automático neste painel.

⌘

Inventário por ADB

Diagnóstico do sistema e do slot. Não altera nenhuma partição.

adb shell getprop ro.boot.slot_suffix
#

Validar ZIP de backup

Compara tamanhos e SHA-256 offline usando Python 3.9+.

python3 tools/backup_audit.py backupprojeto.zip --reference reference/h713-hy310x-20251024.json
✓

Conferir imagem boot

Checa cabeçalho ANDROID!, tamanho e integridade. Não comprova compatibilidade.

python3 tools/validate_boot.py --original boot_a.img --patched magisk_patched.img
HASH LOCAL · NENHUM UPLOAD

Conferir SHA-256 de um arquivo

Escolha uma imagem no seu computador. A comparação ocorre no navegador via WebCrypto; o arquivo não é enviado ao servidor. Limite 128 MiB para preservar memória.
